# M10 V1.5 产品需求与岗位动态生成规则
**功能范围**：企业、组织、岗位列表；不限研发的新岗位创建；岗位名称/职责描述；规则引擎推荐领域能力包；手动添加/删除能力包；生成统一“未来待办 / 过去结果 / 异常 / 个人 Agent”界面；企业和岗位切换；Web/手机同步同一业务对象。
## 职责分析 -> 装配
1. HRM 或 M01 取得岗位定义（创建申请为 proposed）；输入职责文本、组织、适用产品和权限请求。
2. 解析职责产出 duty_codes、object_types、suggested_capability_ids、风险权限。L0 可关键词推断；生产使用受控模型+规则并要求人工确认。
3. 用户选中能力包、对照 M01 授权；严禁“配置=授权”；Owner 签批并发布不可变 versioned manifest。
4. 员工登录取得有效角色、岗位、授权、对象上下文后，服务器组装返回 manifest；所有写入重新检查权限。
5. 变更/撤权留下审计、支持回退，旧业务对象使用当时能力包版本。
## 领域扩展
M04 PLM：立项/需求/结构/BOM/图纸/样品/验证/ECN/技术转移/退市；
M05 CRM：公开线索开发—建档—询盘—报价—订单—交付—回款—售后；
M06 交付、M07 人事行政、M08 品质、M09 财经、M14 NOMI 系统研发均可按能力包注册；模块编号最终依 V7.2.2 最新签批注册表为准。
## 功能验收
RQ01 任意部门可以添加岗位；RQ02 生成结果取决于职责及受控能力包而非固定页面；RQ03 兼岗可组合且不能越权；RQ04 Web/Mobile 展示同一 Action/Result；RQ05 重装配、撤权生效；RQ06 PLM 对接失败不展示虚假已同步；RQ07 Hub 未连接必须标示模拟。
