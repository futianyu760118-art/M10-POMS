# 网页版与手机版 UI/UX 验收规范
## Web >= 1024px
左侧：模块/岗位导航；顶部：企业/岗位/连接状态；主区双栏：待办和结果；管理区：岗位新增、职责编辑、能力包选择、审计与发布。保留键盘操作和宽屏数据表。
## Mobile <= 767px
单栏卡片；底部固定：待办、采集、结果、智能体；醒目的异常和离线状态；表单分步及扫码/拍照/语音替代手填；44px 以上触控热区；横竖屏和安全区域处理。
## 中间屏
768–1023px 采用收缩侧栏或抽屉；禁止横向溢出；断网显示待同步而非已完成。
## 双端必须一致
同岗位/产品/权限时能力包相同，任务数和状态同源；done != verified；撤权后不得再提交；适配失败不展示“实时”；深链链接返回专业系统对应业务对象。
## 测试矩阵
PC Chrome/Edge，移动 iOS Safari/Android Chrome 的关键尺寸；岗位新增、兼岗、低权限、不同产品包、PLM 不可用、重复提交、断网恢复、Hub 模拟标识；P95 响应指标须在真实设备网络下测量。
