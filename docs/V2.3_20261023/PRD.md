## 销售工作流与数据归属
1. 公开获客：M05 线索源，保留可核验的公开来源，禁止未经授权抓取私人资料。
2. 线索建档/评分：M05 客户线索，去重/Owner。
3. 询盘需求：M05+M04，样品、规格和联系记录。
4. 报价商务：M05+M09 成本与毛利约束，版本、审批。
5. 合同订单：M05 商务事实，M06 交期验证。
6. 生产/出货：M06 履约，M08 检验和放行。
7. 应收回款：M09 多币种 AR、核销和催收；POMS 仅视图和 Action。
8. 售后经营：M05 客户与服务，M08 质量追溯。
## UI
首页上方只显示目标、未来待办、异常；底部仅待办/采集/结果；Agent 采用可打开抽屉/详情，任务内快捷入口。采集：扫码->自动匹配对象->动态专业字段->拍照/语音->预览提交。无硬件权限有安全的手动回退。禁用传统 ERP 菜单堆叠。
## 非目标
不自建 HR、ERP、CRM、财务或第二个 Agent Runtime；不自动执行客户承诺、付款和危险设备操作；高风险动作经 Guard。
