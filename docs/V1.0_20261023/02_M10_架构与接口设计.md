## 候选适配 API（需 API 契约正式化）
| 方法 | 候选路径 | 语义 | Owner |
|---|---|---|---|
| GET | /poms/me/manifest | 当前人员 UI 装配 | M10，M01 授权 |
| GET | /poms/me/work-items | 经过权限过滤的任务投影 | M10 引用专业系统 |
| GET | /poms/me/results | 本人历史结果及 EvidenceRef | M10/M02 |
| POST | /poms/action-requests | 幂等命令网关：Guard 后路由专业中心 | M10 入口，专业中心执行 |
| POST | /m07/logistics-requests | 报修专业创建，实际 path 待映射 | M07 |
| GET | /m07/logistics-requests/{id} | 专业状态、业务规则与结果 | M07 |
| POST | /agent/sessions | 受控个人 Agent 会话 | M13/M10 |

## 必备契约要求
任何 ActionRequest 必须有 actor、tenant、resource、action、object_id、policy/guard 决定、idempotency_key、trace_id；写入前由服务端重新校验。调用时应保留 M07 的专业对象事实 Owner，不得直接写 HLC 数据库。M02 的 Evidence 追加/版本化，不可覆盖。

## 异常
失去岗位授权→立即拒绝并清理工作面缓存；重复提交→同一幂等结果；M07 失败→明确失败和重试；M02 暂时不可用→业务结果不得伪装成已归档；跨租户/跨人查询→禁止。

## 安全
M01 RBAC+ABAC + 对象/字段级校验；短会话、租户隔离、敏感字段最小显示、数据不可通过 Prompt 外泄。移动端离线输入若启用必须加密、TTL、冲突处理和撤权清理。
