# M10 工作面、角色装配与移动端 UI V1.0

## 核心原则
首页必须始终突出：**未来的待办 / 过去的报告**。Agent 作为辅助入口，系统菜单只保留与当前人员真实授权相关的行动。一个人的兼岗不等于静态切换成别人的账号。

## 页面清单
| 页面 | 内容 | 数据来源 |
|---|---|---|
| 我的首页 | 待办数、今日异常、任务入口、最近结果 | M10 聚合 M02 |
| 未来待办 | 截止期、来源、优先级、操作入口 | 专业中心引用 |
| 当前异常 | 专业异常/待人工复核及升级 | 各中心/M02 |
| 过去报告 | 结果、审批、验收、证据查看 | M02/各中心 |
| 我的申请 | 请假/报修/培训等授权服务入口 | M07 |
| 我的 Agent | 与当前岗位关联的受控 Skills | M13 |
| 个人设置 | 常用行为偏好、通知、会话 | M10（不改变授权） |

## 装配算法（建议）
1. M01 返回规范 person_id / tenant / 当前有效任职及 Guard 范围。
2. M07 返回岗位职责/资格等业务配置引用（非授权权威）。
3. M10 合并岗位模板（主岗/兼岗/临时代理），去重组件并按 M01 权限过滤。
4. 根据目标、专业中心所分配的任务引用生成首页。
5. 人事异动生效、撤权或租户切换时刷新 manifest 和失效会话。

## 响应式原则
桌面：紧凑导航、任务列表/详情双栏；移动：未来待办优先、单列卡片、低输入成本和明显错误提示，360px 可用。照片/扫码/语音接口按权限、设备与业务系统约束接入，不能仅以 UI 占位代替实际功能。

## 行业包
通用部分 = 身份工作面、待办、审批回执、Result/Evidence、Agent、消息；专用包 = 恒剑灯具或贞观定时器行业表单/Skills/任务类型。切行业不得越权，也不重建个人工作台。
