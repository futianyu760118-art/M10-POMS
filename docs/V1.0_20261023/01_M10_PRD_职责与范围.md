# M10 POMS 产品需求说明 V1.0
**状态：设计候选，待 Owner/Gate 签批**

## 目标
为恒剑不同岗位提供统一且极简的**未来待办、当前异常、过去报告、个人 Agent** 操作入口。岗位界面按 M01 授权后的人员、主岗、兼岗、代理、有效期及专业能力包动态装配，支持 PC 和移动端。

## M10 Own
- `ui_manifest`、`role_template_ref`、`personal_context`、`session_context`、`notification_state`、`local_pending_input`、`sync_state`。
- 个人工作面、专业任务引用、异常提示、结果及证据引用、个人 Agent 会话入口、体验与通知。
- 可审计的操作入口、返回业务源系统、离线草稿管理（后期）。

## Must Not
- 不拥有 Person/Org/Position/Permission/Policy/Guard 权威（M01）。
- 不拥有招聘、任用、薪酬、培训、后勤工单等专业对象（M07）。
- 不拥有 Customer、Order、Product/BOM、Finance、Quality 等专业事实。
- 不复制 M02 Result/Evidence 原件，不让个人 Agent 绕过 M01 / 人工审批写入业务主数据。

## P0 开发能力
| 编号 | 功能 | 必须满足 |
|---|---|---|
| POMS-01 | 我的首页 | 未来待办/过去报告为主，异常提醒可折叠 |
| POMS-02 | 动态岗位装配 | 服务端出具按授权过滤的 manifest，支持兼岗/代理/到期 |
| POMS-03 | 个人申请 | 接受 M07 提供的业务表单能力描述，最小采集 |
| POMS-04 | 待办聚合 | 只保存跨业务任务引用和展示投影 |
| POMS-05 | 结果/证据查看 | 受 M01 授权的 M02 EvidenceRef |
| POMS-06 | 状态反馈 | 幂等请求、加载/错误/重试、回执 trace_id |
| POMS-07 | 移动端基础 | 360px 宽适用、易操作、拍照/扫码入口为后续真实接入预留 |

## P1 / P2
P1：个人 Agent 及授权工具、培训与请假、通知、跨中心融合；P2：离线草稿加密与冲突解决、行业包迁移能力完善。

## 典型角色
员工、人事行政专员（兼后勤）、部门负责人、经营决策者。**DEMO 角色切换仅供展示，不是正式可切换权限**。

## 业务闭环
员工 M10 提交行政报修 → M01 权限校验 → M07 创建专业请求/分派/处理 → 人工验收 → M02 Event/Result/Evidence → M10 个人过去报告回显。

## MVP 不包括
工资核算、自动录用/离职、自动改变岗位授权、人工审批替代、完整低代码编辑器、真实模型未授权工具执行。
