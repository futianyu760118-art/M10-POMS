## Gate
- G0/G1：Owner、System Registry、P0-03/04/05、POMS V2.2 正式原件、接口与身份权威确认。
- G2/G3：报修首条真实业务全链路与结果证据测试。
- G6（W25–28）：M07/M10/HUB 工作面与任务正式试点。
- G7（W29–32）：安全、撤权、离线、AI/Agent 红队与审计。
- G8（W33–36）：最终验收、培训、运营移交、跨行业复制模板。
